# Source discipline

The failure this exists to prevent: a fluent, well-formatted plan whose justifications were
generated rather than found. It reads exactly like a good plan.

## Rules

1. **A URL you did not receive from a tool does not exist.** Never reconstruct a plausible
   URL from memory. `ads.tiktok.com/business/creative-best-practices` may look right and be
   a 404 in front of a judge.
2. **A finding without a URL is dropped.** Not softened, not attributed to "industry
   consensus" — dropped.
3. **Cite what the source says, not what it implies.** If a page says "keep the payoff early",
   do not cite it for "the first 2 seconds decide retention" unless it says that.
4. **Say when you don't know.** "Research returned no usable pattern for this platform" is a
   valid, useful output. Filling the gap is not.
5. **Separate measured from asserted.** Platform documentation reporting its own experiments
   is measured. An agency blog restating it is asserted. Label which you used.
6. **Timestamp everything.** Every finding carries `collectedAt`. The web moves; a pattern
   true in March may be stale.
7. **Never claim a check ran that did not run.** If media was not probed, the plan says so
   rather than implying verified timecodes.

## Applying it

Before presenting any plan, re-read every `citation` field and ask: *did a tool return this
URL in this session?* If the answer is no for any of them, remove that segment and say why.
